# PULSO — demo de boletería para eventos

Página demostrativa para descubrir eventos locales, filtrar la cartelera y seleccionar entradas.

## Ver localmente

Abre `index.html` en un navegador. No requiere instalación ni compilación.

## Incluye

- Cartelera con filtros por categoría y búsqueda.
- Ventana de selección de entradas con cantidad y total estimado, que abre WhatsApp con una solicitud lista para compartir.
- Diseño adaptable a escritorio y móvil.
- Avisos visibles de que los eventos y la compra son demostrativos.

Los nombres, fechas, lugares y precios son ficticios. La demo no procesa pagos ni genera entradas reales; el enlace de WhatsApp abre un mensaje listo para compartir, sin destinatario fijo. Las imágenes se cargan desde Unsplash y las fuentes desde Google Fonts, por lo que requieren conexión a internet.
