# PULSO — boletería para eventos

Demo estática para descubrir eventos locales y seleccionar entradas.

## Publicar localmente

Abre `index.html` en un navegador. No requiere instalación ni compilación.

## Incluye

- Cartelera con búsqueda y filtros para música, escena, comedia y experiencias.
- Selector de cantidad de entradas con total estimado.
- Diseño adaptable a escritorio y móvil.

Los eventos, fechas, lugares y precios son ficticios. La demo no procesa pagos ni emite entradas reales. Las imágenes y fuentes requieren conexión a internet.
